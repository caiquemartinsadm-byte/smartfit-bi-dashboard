# Base de dados

`processed/dashboard_data.csv`: 19 trimestres, incluindo séries CVM e RI separadas.

`processed/financial_data.csv`: receita e lucro da CVM em reais.

Campos vazios representam dados ausentes. Consulte o dicionário e as evidências em `../docs/`. Os CSVs reproduzem a base incorporada ao dashboard. Os arquivos originais CVM e RI não são republicados.
